Each summary is generated from a full plain-text extraction of the source PDF, then written by GLM-5.2 against a fixed 5-section template (citation, one-paragraph summary, detailed Results & Discussion, supplementary-material summary, data availability) — key claims are spot-checked against the raw extracted text before being accepted, not trusted blind. To add a manuscript: drop the PDF in pdf-library/, run pdftotext -layout, run it through the summarization task, add an entry to index.json.
